# references

Reference documentation (generated API docs) for the ApiRTC SDKs.

## Subdirectories

- [apirtc-js](./apirtc-js/) — API documentation for the ApiRTC JavaScript SDK (generated via JSDoc). Contains the per-class/object HTML pages (`Session`, `Call`, `Conversation`, `Stream`, `UserAgent`, `Conference`, `DataChannel`, etc.). See the [CHANGELOG](./apirtc-js/CHANGELOG.md).
- [apirtc-android-sdk](./apirtc-android-sdk/) — API documentation for the ApiRTC Android SDK (generated, Javadoc/Dokka style), package `api-r-t-c`.
- [apirtc-ios-sdk](./apirtc-ios-sdk/) — API documentation for the ApiRTC iOS SDK (generated via Jazzy), with `Classes`, `Enums`, `Protocols`, `Structs` pages.
